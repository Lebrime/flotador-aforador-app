# Registro de Cambios

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.0.0] - 2024

### Agregado
- Funcionalidad completa de aforo con método del flotador
- Cronómetro integrado con precisión de centésimas de segundo
- Almacenamiento local en base de datos SQLite
- Sistema de navegación con React Navigation
- Cálculos automáticos de caudal
- Generación de reportes en PDF
- Historial de aforos con búsqueda
- Pantalla de reportes y estadísticas
- Interfaz intuitiva y responsiva
- Soporte para múltiples idiomas (Spanish/English - Future)

### Características
- Ingreso de parámetros del canal (distancia, espejo de agua, tirante, base menor)
- Registro de múltiples lecturas de tiempo
- Cálculo automático de velocidad y caudal
- Factor de corrección configurable
- Información adicional (ubicación, observaciones)
- Exportación de datos a PDF
- Compartir reportes
- Eliminar aforos
- Estadísticas globales

### Cambios
- Estructura inicial del proyecto
- Configuración de React Native 0.72+
- Setup de navegación con React Navigation 6+

### Correcciones
- N/A (Primera versión)

### Seguridad
- Validación de entrada en todos los formularios
- Almacenamiento local seguro
- Manejo de errores robusto

## Formato

Este archivo sigue el formato de [Keep a Changelog](https://keepachangelog.com/).

### Categorías de Cambios
- **Agregado** (Added): Nuevas características
- **Cambiado** (Changed): Cambios en funcionalidad existente
- **Deprecado** (Deprecated): Características próximas a ser removidas
- **Removido** (Removed): Características eliminadas
- **Corrección** (Fixed): Bugs corregidos
- **Seguridad** (Security): Vulnerabilidades corregidas
